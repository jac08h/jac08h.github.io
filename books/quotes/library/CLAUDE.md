# The Library — orientation for agents

A 3D hall of bookshelves (three.js) where quotes are shelved by year. Click a
spine to open a **two-page reading overlay**: the quote is laid out as real page
text, marker-highlighted, surrounded by blurred illegible filler, and auto-fit so
it never scrolls.

## Files

- `index.html` — canvas, HUD, year rail, fallback, and the overlay DOM. ES module
  with an import map pointing at `vendor/`. No build step.
- `library.js` — entry point: renderer/composer, camera rig, picking, input,
  frame loop. Exposes `window.__library` test hooks (see below).
- `hall.js` — builds the shelf hall geometry, lighting, dust; returns `HALL` +
  bays.
- `books.js` — places book spines per bay from the data.
- `overlay.js` — the opened two-page spread. Highlight + blurred-filler layout
  and `fitType()` (shrinks font until no overflow) live here.
- `textures.js` — procedural canvas textures + `leatherFor`/`hsl` color helpers.
- `vendor/` — pinned three.js bundle. **Committed via `git add -f`** past the
  repo's `vendor/` ignore rule; keep it that way so the view runs as checked out.

## Data

Reads `../data/quotes.json` (fetched at runtime), generated by
`scripts/build_quotes_json.py` from the repo root. Each book: `id, author, title,
year, url, quotes[]`. Quotes vary wildly in length (a few chars up to ~4000) and
may contain `\n` — the overlay must handle both extremes without scrolling.

## Checking your work

Use `rodney` (Chrome automation, in the `all` conda env). `rodney --help` for the
full command list. Typical loop:

```
python3 -m http.server 8877          # from repo root, in the background
rodney start                          # headless; --show to watch
rodney open http://localhost:8877/books/quotes/library/
rodney js "new Promise(r=>{const c=()=>window.__LIBRARY_READY?r(1):setTimeout(c,100);c()})"
rodney js "window.__library.openBookById('2020/20_Dostoevsky__The_Idiot')"  # longest quote — fit stress test
rodney sleep 0.8
rodney screenshot -w 1400 -h 900 /tmp/shot.png   # then Read the PNG
```

Test hooks on `window.__library`: `openBookById(id)`, `openFirstBookOfYear(y)`,
`snapToYear(y)`, `hoverBookByIndex(i)`, `closeBook()`, `state()`,
`screenPointFor(id)`.

Gotchas learned the hard way:
- `rodney screenshot -w/-h` only scales the **capture**, not the JS viewport
  (`window.innerWidth` stays desktop). Media-query/mobile layout can't be
  verified this way — assert on `getComputedStyle`/`innerWidth` instead.
- To confirm "no scrolling", assert `pageFlow.scrollHeight - clientHeight === 0`
  after render, especially on the longest quote.
- Verify both extremes: the longest quote (fit must shrink type) and a
  few-word quote (highlight must sit cleanly mid-page in filler).
